1. 挂载 / fstab —— 最关键，两处都要看
----------------------------------------------------------------------
A) DTB 内的 early fstab（见 dtb_81_baseline\fstab_nodes.txt）
   /firmware/android/fstab/system   fsmgr_flags = "wait,verify"   status = "ok"
   /firmware/android/fstab/vendor   fsmgr_flags = "wait"          status = "disabled"
B) /vendor/etc/fstab.qcom（2,879 B，本目录 vendor__etc__fstab.qcom）
   #/dev/block/.../system  /system  ext4  ro,...  wait,verify   <<< 该行被注释
   /apps       wait
   /oem        wait,verify
   /data       wait,resize,forceencrypt=footer,quota      （FDE 全盘加密）
   /cache /dsp /firmware(modem) /bt_firmware /misc /sdcard1 /USB OTG
=> system 挂载由 DTB 提供，文件里这份只管其它分区；vendor 节点 disabled = 非 Treble。
=> 做包必改：把 DTB 中 system 节点 fsmgr_flags 的 "verify" 去掉并重新打包 boot；
   若动 oem 也要处理它的 verify；若要免加密，去掉 forceencrypt=footer 并清 data。
=> 内核侧：CONFIG_DM_VERITY=y、CONFIG_DM_VERITY_FEC=y；
   CONFIG_EXT4_ENCRYPTION / CONFIG_FS_ENCRYPTION 未设置（无 FBE，只有 FDE）。
